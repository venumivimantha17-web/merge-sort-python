# Merge Sort in Python

A simple implementation of the **Merge Sort** algorithm using Python.

## About

Merge Sort is a sorting algorithm based on the **divide-and-conquer** principle. It divides an unsorted list into smaller sublists, recursively sorts them and then merges the sorted sublists to produce the final sorted list.

## Features

- Implements Merge Sort from scratch
- Uses recursive division of the list
- Sorts the list in ascending order
- Demonstrates the divide-and-conquer approach
- Includes a simple example for testing
